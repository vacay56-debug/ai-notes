Claude 使用者指引 ／ 六層架構

使用 Claude
你必須知道的事

從「在哪裡開啟」到「串接了什麼」，六個層次構成完整的使用決策路徑。每一層都是一次選擇，選對了，產出品質才會穩定。

01

從哪裡開啟

Where you open it

瀏覽器版

claude.ai

免安裝，權限鎖定的公務筆電也能直接使用。

Chrome 擴充

Claude in Chrome

讀取你正在瀏覽的分頁，代為點擊與填寫表單。

行動版

Claude on Mobile

iOS 與 Android。同一帳號、同一份對話紀錄，隨處接續。

桌面版

Claude on Desktop

與本機的真實檔案、資料夾及應用程式並行作業。

唯一能觸及本機檔案的入口
02

挑哪一顆腦

Which brain you pick

Claude Haiku

FAST & LIGHT

快速輕量。適合高頻次、單純的任務。

Claude Sonnet

DAILY DRIVER

日常主力。速度與智慧的平衡點。

Claude Opus 5

HARD THINKING

硬派思考。判斷、分析，以及條件混亂的任務。

Claude Fable 5

FRONTIER TIER

前沿層級。任務真的困難時才動用。

Claude Mythos

RESTRICTED

限特定組織使用，尚未公開釋出。

選擇原則

RULE OF THUMB

先問任務難度，而非先問模型名稱。單純作業用小模型，才不會把等待時間花在沒有價值的地方。

03

思考多用力

How hard it thinks

低強度

LOW EFFORT

格式整理、資料擷取、清稿。答案一樣，但更快。

中強度

MEDIUM EFFORT

日常工作。草擬、摘要、編修。

高強度

HIGH EFFORT ／ 預設

預設值。分析與需要真正下判斷的決策。

最高強度

MAX EFFORT

只在任務確實值得這段等待時才用。

陷阱｜THE TRAP　想得更久不等於更正確。過長的推理，只是給了它更多空間去自信地犯錯。
04

怎麼工作

How you work

對話

CHAT

一問一答。多數人一輩子停在這裡。

專案

PROJECTS

檔案與指令只載入一次，之後每次開新對話都已經進入狀況。

協作模式

COWORK

把整件事交出去然後離開。適合多步驟的完整任務。

Claude Code

FOR DEVELOPERS

為開發者而生，也是讓 Claude 實際動手執行最快的一條路。

Claude Design

CANVAS

簡報、原型與視覺的畫布，用對話就能改。

內建於既有工具

WORKS INSIDE YOUR TOOLS

Chrome ・ Excel ・ PowerPoint ・ Slack

05

拿到什麼

What you get back

成品物件

ARTIFACTS

不是一整面文字牆，而是一份可以繼續編輯的文件、儀表板或簡報。

真實檔案

REAL FILES

Word、Excel、PowerPoint、PDF。下載後直接寄出。

即時儀表板

LIVE ARTIFACTS

每次開啟，都會以你的真實資料重新整理。

06

串接了什麼

What it's plugged into

連接器

CONNECTORS

Gmail、Drive、Calendar、Notion、Slack、HubSpot 等數十種服務。

記憶

MEMORY

把重要的事帶到下一次對話，不必再從頭自我介紹。

技能

SKILLS

指令寫一次，之後每一次對話都照著做。

六層合起來看 入口決定能碰到什麼、模型決定思考品質、強度決定成本與時間、模式決定交付範圍、產出決定能不能直接用、串接決定它認不認識你的工作。任何一層選錯，後面幾層都補不回來。
