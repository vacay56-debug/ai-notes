Claude 的四種工作模式 多數人只用其中一種——不同工作，應選用不同工具

附件核心論點：人工智慧（Artificial Intelligence, AI）正從回答問題，轉變為實際參與工作。四種模式並非版本高低之分，而是依「工作型態」區隔的四種介面。

二、各模式詳述

Mode by Mode
1

Claude AI

THINK WITH IT
用它「思考」

定位為日常對話層，是最通用、無須任何前置設定的入口。

適用任務

  • 撰寫（Write）
  • 研究（Research）
  • 發想（Brainstorm）
  • 摘要（Summarize）
  • 分析（Analyze）
  • 釐清構想（Work through ideas）

優點

  • 零設定即可使用
  • 泛用、彈性高

限制

  • 無系統存取權限
  • 後續行動與資訊串接仍須由使用者完成
最適用於：思考、學習，以及更快取得較佳答案。
2

Claude Code

BUILD WITH IT
用它「建造」

在終端機中運作的自主編碼代理（Autonomous Coding Agent），可直接對程式庫動手。

適用任務

  • 跨檔案協同作業
  • 功能除錯
  • 程式庫重構
  • 撰寫並執行測試
  • 開發完整功能模組

優點

  • 完全自主執行
  • 具備深度程式庫脈絡理解

限制

  • 產出須審慎覆核
  • 產生使用成本
最適用於：希望 AI 代理能真正動手處理程式碼的開發者。
3

Claude Cowork

OPERATE WITH IT
用它「執行」

面向非開發者的桌面助理，把代理能力帶到一般行政與知識工作。

適用任務

  • 整理與重新命名檔案
  • 自 PDF 擷取資料
  • 填寫試算表
  • 處理重複性作業
  • 在不同應用程式之間搬運資訊

優點

  • 無須撰寫程式
  • 支援跨應用工作流

限制

  • 測試／早期階段產品
  • 可控性與組態彈性較低
最適用於：想橫跨自身工具與檔案、自動化實際業務的任何使用者。
4

Claude Design

DESIGN WITH IT
用它「設計」

視覺工作的創意夥伴，以畫布搭配對話進行迭代。

適用任務

  • 建立網站
  • 設計線框圖（Wireframe）
  • 製作簡報
  • 探索版面配置
  • 生成創意概念

優點

  • 概念成形速度快
  • 視覺發想能力強

限制

  • 仍需人為審美判斷
  • 最終精修環節不可省略
最適用於：從快速構想到細緻設計的視覺產出與打磨。
