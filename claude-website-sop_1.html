Claude Code Workflow · 9 Steps

用 Claude 打造網站的
標準作業程序

一套用來消除「AI 既視感」的 9 步驟工作流程。核心概念是讓三份 Markdown 檔案——事實、文案、風格——分別把關，讓 Claude 在每個階段都依據明確依據建置，而不是憑空生成。

terminal
$ claude /model
→ 已選擇 Fable 5
$ 讀取 CONTEXT.md、COPY.md、DESIGN.md ...
→ 依三份檔案建置頁面，逐頁截圖並自我審查
$
貫穿全流程

三份檔案，決定整個建置結果

每個步驟都只做一件事：把資訊寫進對的檔案。Claude 之後的每一次產出，都回頭依據這三份檔案檢核。

CONTEXT.md

網站建置所依據的事實資料——公司背景、產品內容、目標客群等，不容 Claude 自行想像。

COPY.md

網站上的每一句文字：每個標題、每個段落、title 標籤、meta 描述，以及各頁的 SEO 地圖。

DESIGN.md

視覺風格規範：色彩、字型與元件系統，決定網站最終呈現的樣貌。

Phase 1 · 檔案準備

THE FILES

在寫任何一行程式碼之前，先把「事實」與「文案」確立下來，並逐字取得核准。

1

撰寫事實檔案

Claude Chat 透過過往數月的對話已經對你有一定了解。下載它草擬出的檔案，放進專案資料夾，並修正其中不正確之處。

貼上這段 · Claude Chat
不要假設這個網站與我有關。請建立一份 CONTEXT.md，保存建置此網站所依據的事實。一次只問我一個問題，等我確認後再問下一題。不要憑空捏造任何內容。
2

讓 Claude 訪談你

建立一個資料夾，在該處開啟終端機，輸入 claude，並以 /model 指令選擇 Fable 5。之後由你負責回答問題，草擬文字則交給 Claude。

貼上這段
請閱讀 CONTEXT.md。先提出網站的頁面架構建議，再逐頁訪談我，只詢問資料缺漏之處，以及每個頁面應鎖定的目標排序。將所有文案草擬至 COPY.md。
3

任何程式碼產生前，先核准每一字句

告訴 Claude 需要修改的地方，它會直接編輯檔案。在任何程式碼被寫出之前，COPY.md 中的每一字句都必須先經過你的核准。

COPY.md 應保存：每個標題、每個段落、title 標籤、meta 描述，以及每個頁面的 SEO 地圖。

Phase 2 · 建置

THE BUILD

三份檔案就緒後，才開始真正動手建置，並且每一步都要求 Claude 自我驗證。

4

融合品牌風格與喜愛的網站

從 Refero Styles 下載約五個你喜歡的網站的 DESIGN.md，連同你的品牌素材一起拖曳進 Claude Code。

貼上這段
請將這些檔案合併成一份 DESIGN.md。色彩與字型由我的品牌決定；版面配置與整體氛圍則參考這些範例。
5

建置後立即驗證

Claude 依據三份檔案進行建置，接著為每個頁面截圖，並在你載入網站之前先自行審查輸出結果。

貼上這段
請閱讀 DESIGN.md，並使用你的前端設計技能。依照 COPY.md 的文案逐字建置網站，絕不可自行捏造標誌或數據。為每個頁面截圖，對照 DESIGN.md 進行審查，並修正未通過的項目。
6

加入功能元件

像 21st.dev 這類元件庫，會在每個元件下方附上可直接複製貼上的提示詞。Claude 會保留其中的工程邏輯，並移除多餘的部分。

21st.dev · 加入 CLAUDE.md（若尚未建立則新增）
貼上的元件屬於結構性素材：它們提供骨架，DESIGN.md 提供外觀，COPY.md 提供文字內容。
Phase 3 · 修飾

THE POLISH

最後一哩路：把網站從「堪用」修到「有質感」。

7

Higgsfield 主視覺影片

將完成的影片拖入 Claude Code，下指令「將此設為主視覺背景」，它會自動把 23MB 的檔案壓縮至 2.3MB。

貼上這段 · Higgsfield
GPT Image 2：建立一張水粉畫風格的圖像，呈現優美風景與深藍色天空。接著以 Kling 3.0 轉為影片：畫面主體維持不動，僅背景場景緩慢流動。
8

大量反覆修改

以自然語言持續反覆修改，多半透過語音輸入：說出問題所在、觀察變化、再說出下一項修改。難以描述的問題，直接截圖說明。

「把按鈕往上移。」 「把卡片加寬一點。」 「這個區塊感覺太擠了，加一點留白。」
9

品味把關

常見問題是同時執行五種環境動畫效果。解法：每個版面只採用一套動態系統。搭配 taste-skill 或 Impeccable 技能安裝效果更佳——貼上任一 repo 連結，並說「安裝這個技能」。

貼上這段 · 上線前使用
如果讓品味評論家來看，他會怎麼說？
✓

使用 Vercel 部署上線

準備好網站上線，並使用 Vercel CLI 進行部署。32 秒內即可完成，除既有的 Claude 方案外，無需額外付費。範例成果：charliehills.ai。
