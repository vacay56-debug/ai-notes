LLM 大型語言模型 Large Language Model

定義

具備通用語言理解能力，可生成近似人類語言的文本回應。透過海量文本語料預訓練，習得語法、知識與推理能力，為當前生成式 AI 的主流架構。

運作流程

輸入 Input→ 詞元化 Tokenization→ 嵌入 Embedding→ Transformer 運算→ 輸出 Output

文字先切分為詞元（Token），轉換為高維向量後，由 Transformer 的自注意力機制（Self-Attention）逐層運算，最終以「預測下一個詞元」方式生成回應。

技術特性

  • 自迴歸生成（Autoregressive Generation）：逐詞元預測，累積形成完整回應。
  • 上下文學習（In-Context Learning）：無需重新訓練，僅憑提示範例即可調整行為。
  • 湧現能力（Emergent Abilities）：參數規模達臨界點後出現推理、翻譯等未明確訓練之能力。
  • 限制：可能產生幻覺（Hallucination），知識存在訓練截止時間。

代表模型

GPT-4 / GPT-4o（OpenAI）、Claude（Anthropic）、Gemini（Google）、Llama（Meta）、Qwen（阿里巴巴）

LCM 大型概念模型 Large Concept Model

定義

由 Meta 提出之新型架構，在「潛在空間」（Latent Space）中以句子為單位進行快速生成，而非逐詞元運算，針對高效推理進行最佳化。

運作流程

輸入 Input→ 句子切分 Sentence Segmentation→ SONAR 嵌入→ 擴散過程 Diffusion→ 進階模式化 / 隱藏處理→ 量化 Quantization→ 輸出 Output

SONAR 為 Meta 開發之多語言句子嵌入空間，支援 200 種以上語言。模型在此概念空間中以擴散（Diffusion）方式預測「下一個概念」，最後解碼回自然語言。

技術特性

  • 概念層級運算：以句子（概念）為基本單位，而非詞元，運算單位更大、步驟更少。
  • 語言無關性：概念空間與具體語言解耦，天然支援跨語言與跨模態遷移。
  • 長文本效率：處理長文件時，運算量成長幅度低於逐詞元的 LLM。
  • 現況：屬研究階段架構（Meta 於 2024 年底發表論文），尚未大規模商用。

代表模型

Meta LCM（研究原型，基於 SONAR 嵌入空間）

LAM 大型行動模型 Large Action Model

定義

理解使用者目標與行為意圖，能規劃並執行複雜任務的模型架構，為 AI 代理（AI Agent）之核心技術，從「回答問題」進化為「完成工作」。

運作流程

輸入處理 Input Processing→ 感知系統 Perception System→ 意圖辨識 Intent Recognition→ 任務拆解 Task Breakdown→ 行動規劃 Action Planning→ 神經符號整合→ 回饋整合 Feedback Integration

模型結合記憶系統（Memory System）保存任務狀態，透過神經符號整合（Neuro-Symbolic Integration）將神經網路的彈性與符號邏輯的精確性結合，執行後依回饋修正下一步行動。

技術特性

  • 目標導向：以「達成任務」為輸出，而非僅生成文字。
  • 工具使用（Tool Use）：可呼叫應用程式介面（Application Programming Interface, API）、操作軟體介面、執行多步驟工作流。
  • 閉環修正：具備「規劃—執行—觀察—修正」循環，容錯能力優於單次生成。
  • 應用場景：自動化行政流程、跨系統操作、代理式工作流（Agentic Workflow）。

代表模型

Rabbit LAM（Rabbit R1 裝置）、Claude Computer Use / Claude Code（Anthropic）、OpenAI Operator、各類 Agent 框架（LangGraph、AutoGen）

SAM 影像分割模型 Segment Anything Model

定義

由 Meta 開發之通用影像分割模型，可依據提示（點選、框選、文字）從影像中分割任意物件，產出精確的影像遮罩（Mask）。

運作流程

影像輸入 Image Input→ 影像編碼器 Image Encoder→ 影像嵌入 Image Embedding
提示輸入 Prompt Input→ 提示編碼器 Prompt Encoder→ 特徵關聯 Feature Correlation→ 遮罩解碼器 Mask Decoder→ 分割輸出 Segmentation Output

影像與提示分別編碼後，於遮罩解碼器中融合，數十毫秒內即可產出分割結果，支援互動式即時操作。

技術特性

  • 零樣本分割（Zero-Shot Segmentation）：未見過的物件類別亦可分割，無需針對特定領域重新訓練。
  • 提示彈性：支援點、框、粗略遮罩、文字等多種提示形式。
  • 訓練規模：以 SA-1B 資料集（11 億個遮罩、1,100 萬張影像）訓練。
  • 應用場景：醫療影像標註、災害空拍判讀、地理資訊分析、影像編輯。

代表模型

SAM / SAM 2（Meta，SAM 2 延伸支援影片即時分割）

MoE 專家混合模型 Mixture of Experts

定義

將模型拆分為多個「專家」子網路，由路由機制依輸入內容選擇性啟用部分專家，在維持大參數規模的同時大幅降低單次推理成本，提升效率與可擴展性。

運作流程

輸入 Input→ 路由機制 Router Mechanism→ 專家 1～N Experts→ Top-k 選擇→ 加權組合 Weighted Combination→ 輸出 Output

路由器為每個詞元計算各專家的適配分數，僅啟用分數最高的 k 個專家（常見 k=2），其輸出依權重加總後傳遞至下一層。

技術特性

  • 稀疏啟用（Sparse Activation）：總參數量大，但單次推理僅動用一小部分，推理成本接近小模型。
  • 專家分工：不同專家自然分化出對特定語言、領域或任務型態的專長。
  • 訓練挑戰：需負載平衡機制避免路由集中於少數專家。
  • 屬架構設計而非獨立模型類型：可與 LLM、VLM 等架構結合使用。

代表模型

Mixtral 8x7B / 8x22B（Mistral AI）、DeepSeek-V3、Switch Transformer（Google）、Qwen-MoE

MLM 遮罩語言模型 Masked Language Model

定義

透過預測被遮罩的詞元進行學習，建立雙向的上下文語言表徵。有別於 LLM 的單向生成，MLM 同時參照左右語境，長於「理解」而非「生成」。

運作流程

文本輸入 Text Input→ 詞元遮罩 Token Masking→ 嵌入層 Embedding Layer→ 左語境 + 右語境→ 雙向注意力 Bidirectional Attention→ 遮罩詞元預測→ 特徵表徵 Feature Representation

訓練時隨機遮蓋約 15% 詞元（如「臺灣的 [MASK] 是臺北」），模型須同時利用前後文推測遮罩內容，藉此習得深層語意結構。

技術特性

  • 雙向語境（Bidirectional Context）：每個詞元的表徵同時融合前文與後文資訊。
  • 編碼器架構（Encoder-Only）：輸出為語意向量，適合下游任務微調（Fine-tuning）。
  • 應用場景：文本分類、命名實體辨識、語意檢索、嵌入向量生成（為檢索增強生成 RAG 之基礎元件）。
  • 限制：不擅長開放式文本生成。

代表模型

BERT（Google）、RoBERTa（Meta）、ALBERT、DeBERTa（Microsoft）

SLM 小型語言模型 Small Language Model

定義

輕量化且資源高效的語言模型，參數量通常介於數億至數十億，可於手機、筆電或嵌入式裝置上本機執行，為邊緣部署（Edge Deployment）之理想選擇。

運作流程

輸入處理 Input Processing→ 精簡詞元化 Compact Tokenization→ 高效 Transformer→ 模型量化 Quantization→ 記憶體最佳化→ 邊緣部署 Edge Deployment→ 輸出生成 Output Generation

透過量化（如將 16 位元浮點數壓縮為 4 位元整數）、知識蒸餾（Knowledge Distillation）與架構精簡，於有限運算資源下維持可用性能。

技術特性

  • 本機執行：資料不離開裝置，隱私與資安風險低，適合敏感性業務環境。
  • 低延遲、可離線：不依賴網路連線與雲端服務。
  • 高品質資料訓練：以「教科書等級」資料彌補參數規模限制（如 Phi 系列）。
  • 取捨：複雜推理與長文本能力仍與大型模型有落差。

代表模型

Phi-3 / Phi-4（Microsoft）、Gemma（Google）、Llama 3.2 1B/3B（Meta）、Qwen 小型版本

VLM 視覺語言模型 Vision-Language Model

定義

同時處理文字與影像的多模態模型，可理解圖片內容並以自然語言回應，實現「看圖問答」、文件判讀與圖表分析等多模態理解能力。

運作流程

影像輸入 Image Input→ 視覺編碼器 Vision Encoder→ 投影介面 Projection Interface
文字輸入 Text Input→ 文字編碼器 Text Encoder→ 多模態處理器 Multimodal Processor→ 語言模型 Language Model→ 輸出生成 Output Generation

影像經視覺編碼器（多為 ViT 架構）轉為視覺特徵，再透過投影層對齊至語言模型的嵌入空間，使語言模型能「讀懂」影像並統一生成回應。

技術特性

  • 模態對齊（Modality Alignment）：核心技術在於將視覺與語言特徵映射至共同語意空間。
  • 文件智慧：可判讀掃描文件、表格、圖表、手寫文字，支援光學字元辨識（Optical Character Recognition, OCR）類任務。
  • 應用場景：公文影像判讀、簡報圖表分析、現場照片研判、無障礙輔助描述。
  • 發展趨勢：與影片理解、空間推理及機器人視覺整合。

代表模型

GPT-4o（OpenAI）、Claude（視覺能力）（Anthropic）、Gemini（Google）、LLaVA、Qwen-VL

選型觀點

八種類型並非互斥，而是不同維度的分類：LLM、MLM、SLM 依「規模與訓練目標」區分；VLM、SAM 依「模態」區分；MoE 是「架構設計」；LAM 是「能力層級」；LCM 是「運算單位」的新研究方向。實務上一個產品可能同時具備多種屬性，例如 GPT-4o 同時是 LLM、VLM，且據推測採用 MoE 架構。

實務選型三原則：需要生成與推理選 LLM／VLM；需要自動化執行任務選 LAM（代理框架）；資安敏感或離線環境選 SLM 本機部署。MLM 則多以嵌入模型形式存在於檢索系統底層，一般使用者不直接接觸。
