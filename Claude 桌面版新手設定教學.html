Claude 桌面版新手設定教學

依照實際操作順序，從主畫面出發，經過帳號選單、偏好設定、自訂功能，最後到方案與用量。每張截圖上的編號，對應右側（或下方）同編號的說明。滑鼠移到說明上，截圖上的編號會放大。

適用版本Claude 桌面版（Windows）
開啟設定快捷鍵Ctrl + ,（逗號）
介面語言截圖為英文，本文附中文對照
1

認識主畫面與側邊欄

路徑：開啟 Claude 桌面版 → 看左側邊欄

登入後，左側邊欄是所有功能的入口。由上到下依序是：導覽列、主要功能、排程與釘選、對話清單。

  1. 頂端導覽列由左至右：收合側邊欄、上一頁／下一頁，右側是「對話（氣泡圖示）」與「程式碼（</>）」模式切換。一般使用停在對話模式即可。
  2. New（新增）開啟一個全新對話。換主題就開新對話，回應會比較準確。
  3. Projects（專案）把同一主題的對話、參考檔案與自訂指示集中管理，適合長期業務。
  4. Artifacts（成品）集中檢視 Claude 替你產出的網頁、文件、小工具等成品。
  5. Scheduled（排程）建立定時自動執行的任務，例如每週固定產出的簡報整理。
  6. Dispatch（Beta）測試版功能，用於把任務交辦給桌面版 Claude 執行。功能仍在調整，細節以官方說明為準。
  7. Customize（自訂）進入 Skills、Connectors、Plugins，詳見步驟 4。
  8. More（更多）展開其餘功能項目。
  9. 排程任務清單「Scheduled」區列出已建立的排程；右側的 Weekly 表示每週執行。
  10. Pinned（釘選）常用對話可釘選在此，點開箭頭展開。
  11. Chats and tasks（對話與任務）歷史對話清單。放大鏡可搜尋，右側篩選圖示可調整顯示方式。

小提示：對話標題可讓你日後用搜尋找回內容。重要對話建議釘選。

2

開啟帳號選單

路徑：側邊欄底部的帳號名稱 → 選單

帳號選單集中了設定、語言、說明與方案。截圖中的登入信箱已遮蔽。

  1. 目前登入的帳號最上方顯示登入中的帳號，確認自己沒有登入錯帳號。
  2. Settings（設定）進入完整設定頁。快捷鍵 Ctrl + ,（逗號），Mac 為 Cmd + ,。下一步主要就在這裡操作。
  3. Language（語言）切換介面顯示語言，可改成繁體中文。
  4. Get help（取得協助）開啟說明中心與客服入口。
  5. View all plans（查看所有方案）比較各訂閱方案與額度，見步驟 5。
  6. Get apps and extensions下載手機版、瀏覽器擴充功能等其他 Claude 應用。
  7. Learn more（了解更多）有子選單，可查看使用政策、隱私權等說明文件。
  8. Log out（登出）登出目前帳號。共用電腦使用完畢務必登出。

如果介面想改成中文：Language 可調整介面語言；步驟 3 的 Voice → Language 是語音功能的語言，兩者是不同設定。

3

設定 → Preferences（偏好設定）

路徑：帳號選單 → Settings → Preferences

偏好設定分為外觀、語音、通知三塊，是新手第一個要調整的頁面。左側是設定分類，右側是內容。

  1. 目前所在：Preferences左側欄反白處就是目前頁面。其他分類見下方對照表。
  2. Theme（主題）三個圖示由左至右：跟隨系統（螢幕）、淺色（太陽）、深色（月亮）。長時間閱讀或夜間使用可選深色。
  3. Chat font（對話字體）決定對話區的字型，截圖為 Anthropic Serif（襯線體）。覺得閱讀吃力可換成無襯線字體。
  4. Motion（動態）System 依系統設定；Reduced 減少回應串流與介面動畫，對動態敏感或想要畫面穩定者適用。
  5. Voice → Language（語音語言）語音對話使用的語言，截圖為 English。若要用中文語音，請改成中文。
  6. Voice → Style（語音風格）語音的聲音與說話風格，截圖為 Buttery。可逐一試聽挑選。
  7. Voice → Speed（語速）語音播放速度，預設 Normal。
  8. Notifications → Response completions開啟後，Claude 回應完成時會通知你。跑長任務（研究、排程）時很實用。藍色代表已開啟。

4

設定 → Customize（自訂）

路徑：Settings 左側欄向下捲動 → Customize

設定左側欄較長，需要向下捲動才會看到底部的 Customize 區。這裡決定 Claude 能「多會做什麼」與「能連到哪些服務」。

  1. Skills（技能）可重複使用的工作說明書，例如固定的文件格式、審查清單。啟用後 Claude 會在符合情境時自動套用。
  2. Connectors（連接器）把 Claude 連到外部服務，例如信箱、雲端硬碟、行事曆。授權後 Claude 才讀得到那些資料。
  3. Plugins（外掛）把工具、指令與技能打包成一組，一次安裝，適合團隊統一工作流程。
  4. Response completions與步驟 3 相同的通知開關，捲動後在此畫面同樣可見。

資安提醒：連接器一旦授權，Claude 就能讀取該服務的內容。公務使用請先確認機關資安規範，機敏或涉密資料不應交給外部 AI 服務處理，授權範圍也建議只開必要項目。

5

方案與用量：Upgrade 頁面

路徑：帳號選單 → View all plans（或 Billing／Usage）

看到「Upgrade in the iOS app」代表你的訂閱是透過 Apple App Store 建立，方案變更必須回到 iPhone／iPad 的 Claude App 處理，網頁版無法直接升級。

  1. 標題與說明告知你經由 App Store 訂閱，因此升級或更換方案只能在 iOS App 內進行。
  2. Scan with your phone用手機相機掃描 QR Code，會開啟手機上的 Claude App，再依畫面調整方案。（截圖中的 QR Code 已遮蔽）
  3. Buy usage credits額度用完但不想換方案時，可加購用量點數。需綁定信用卡，App Store 訂閱維持不變。
  4. Back to Claude不做任何變更，返回 Claude。

要取消或管理 App Store 訂閱：在 iPhone 開啟「設定」→ 點選最上方 Apple ID →「訂閱項目」，找到 Claude 後管理。

想知道用量剩多少：回到 Settings 左側欄的 Usage（用量）查看。

✓

新手設定清單

依重要性排序，做完即可開始使用

  1. 在 Preferences 選好主題與字體，讓長時間閱讀舒服。
  2. 開啟 Response completions，長任務完成會通知你。
  3. 到 Privacy 與 Memory 看過一遍，確認你能接受的資料處理方式。
  4. 需要串接信箱或雲端硬碟時，才到 Connectors 授權，並只開必要範圍。
  5. 把固定的工作流程整理成 Skills，之後直接重複使用。
  6. 用量吃緊時，先看 Usage；若是 App Store 訂閱，方案變更回 iOS App 處理。
