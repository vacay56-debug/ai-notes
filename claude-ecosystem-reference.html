Claude 生態系統對照手冊

本表依用途分類整理 Claude 目前主要工具與功能模組，供工作流程選型參考。內容為獨立整理而非 Anthropic 官方文件，功能持續迭代中，正式規格請以 docs.claude.com 為準。

專案Projects固定工作區，保留檔案與指令設定需跨多次對話延續脈絡的長期案件網頁／桌面版

壹

對話

Chat
定位Claude 的預設入口，處理提問、討論、寫作、研究與摘要。
關鍵能力網頁搜尋、圖像辨識、長文脈絡、逐步推理、可生成成果物。
使用時機單次或多輪對話即可完成的任務，不需要跨對話持久狀態。
貳

專案

Projects
定位將特定案件的指令、參考檔案與對話紀錄集中保存的工作區。
關鍵能力自訂指令、檔案庫、對話串共用同一組脈絡。
使用時機長期追蹤的政策案、需反覆引用同批資料的工作。
參

成果物

Artifacts
定位獨立顯示、可反覆編輯的產出物件（文件、程式、圖表、網頁）。
關鍵能力與對話脫鉤呈現、支援版本修改、可下載或分享。
使用時機產出需離開對話框單獨檢視、留存或交付的內容。
肆

技能

Skills
定位封裝特定作業最佳實務的可重複套用模組（含範本、腳本）。
關鍵能力依任務類型自動觸發、確保產出格式與品質一致。
使用時機機關內部制式文件（如公文、預算書、招標文件）的固定產製流程。
伍

連接器

Connectors
定位將 Claude 接上外部服務（雲端硬碟、信箱、日曆等）的介接層。
關鍵能力即時讀取外部資料、減少人工搬移資訊的步驟。
使用時機需跨系統整合，例如彙整信件、行事曆或雲端文件內容。
陸

記憶

Memory
定位跨對話累積使用者偏好與脈絡，減少重複說明。
關鍵能力背景延續性、逐步提升回應精準度。
使用時機長期、高頻互動場景；可於設定中關閉或調整。
柒

Cowork

Desktop Agent
定位具備本機資料夾存取權限的桌面代理人，可自主執行多步驟任務。
關鍵能力讀寫本機檔案、排程任務、跨應用程式協作。
使用時機交辦式、非對話式的整批作業，如批次文件整理。
捌

Claude Code

Developer Tool
定位於終端機／IDE 內運作的程式開發代理人。
關鍵能力讀取專案結構、撰寫並執行程式、版本控制整合。
使用時機程式開發、除錯、自動化腳本建置。
