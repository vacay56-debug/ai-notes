事前準備

建立帳號與遠端儲存庫（Repository），作為所有檔案的存放位置。

  1. 前往 github.com 註冊帳號。
  2. 點右上角 ＋ → New repository。
  3. 填 Repository name（例：my-project），選 Public 或 Private。
  4. 勾選 Add a README file，按 Create repository。

方法 A：網頁直接上傳

適合檔案不多、不想碰指令的新手。全程在瀏覽器完成。

  1. 進入你的儲存庫頁面。
  2. 點 Add file → Upload files。
  3. 把檔案／資料夾拖曳進上傳區。
  4. 下方填寫變更說明（Commit message，例：首次上傳）。
  5. 按 Commit changes。

方法 B：Git 指令上傳

正式的版本控制流程，適合長期維護的專案。

① 安裝 Git

下載安裝：git-scm.com/downloads

② 首次設定身分（只需一次）

terminal — 設定身分
git config --global user.name "你的名字"
git config --global user.email "你的Email"

③ 上傳專案（在專案資料夾內執行）

terminal — 首次上傳
git init                          # 初始化 Git
git add .                         # 加入所有檔案
git commit -m "首次上傳"           # 建立版本紀錄
git branch -M main                # 命名主分支
git remote add origin https://github.com/帳號/儲存庫名.git
git push -u origin main           # 推送到 GitHub
!
第一次 push 會要求登入驗證，請使用 Personal Access Token，而非密碼。

④ 之後每次更新（三行搞定）

terminal — 日常更新
git add .
git commit -m "更新說明"
git push
✕

常見卡關處理

遇到錯誤先對照下表，多數狀況一步即可解。

問題解法
push 要密碼但一直失敗用 Token 代替密碼：Settings → Developer settings → Personal access tokens
remote origin already exists先 git remote remove origin 再重新加入
檔案太大（>100MB）GitHub 不接受，改用 Git LFS 或先壓縮
想忽略某些檔案建立 .gitignore，寫入不上傳的檔名
新手建議 → 先用 方法 A（網頁上傳）快速上手，熟悉後再學 方法 B（Git 指令）做正式版本管理。需要的話，可另外產一份 .gitignore 範本或 Personal Access Token 申請步驟。
