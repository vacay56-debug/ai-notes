STEP 01

選擇筆記軟體與資料夾架構

從一套將檔案留在自己電腦上的純筆記軟體開始。Obsidian（筆記軟體）是常見的免費選項。接著，將所有內容歸入四個資料夾——PARA（Projects, Areas, Resources, Archives）架構。

PARA / 01

Projects

專案
有明確期限、需要完成的任務。
範例　發布、課程、報告
PARA / 02

Areas

領域
需要長期維護、沒有終點的生活面向。
範例　健康、財務、工作
PARA / 03

Resources

資源
值得保存、供日後查閱的主題。
範例　指南、筆記、靈感
PARA / 04

Archives

封存
已結束、暫不使用的舊資料。
範例　完成的專案、過去的筆記
四個資料夾——這就是這套系統的全部。
ONLY THIS FOLDER
STEP 02

讓 AI 連上你的檔案

授權一套 AI 工具讀寫筆記資料夾。Claude Cowork（Claude 協作工具）內建於 Claude 應用程式中，能直接在你的電腦上開啟、編輯並儲存檔案。

只指向筆記資料夾，不開放其他權限——確保它只碰觸你允許的內容。

Claude Code 與 Hermes Agent 可達成相同效果，兩者皆提供簡易應用程式版本，不需使用終端機（terminal）。

STEP 03 — 04

每日循環

SAVE 存檔

發現值得保留的內容時，直接交給 AI。它會挑選正確的資料夾並完成儲存，再回傳檔案連結供你確認。無需猜測檔案該放哪裡。

幫我找出關於定價策略的筆記
SAVE → FIND
FIND 尋找

之後需要用到時，直接問 AI。它會讀取所有筆記，在幾秒內給出答案。無需翻找、開啟、關閉、重複。

CLOUD BACKUP
STEP 05

備份到雲端

將筆記資料夾連結至一個免費的 GitHub（程式碼託管平台）帳號。GitHub 會在雲端保留一份安全副本——即使電腦損壞，你的第二大腦仍然存在。

讓 AI 負責同步雲端副本與本機檔案——你的電腦與雲端，隨時保持一致。

現在，你的筆記存在於兩個地方，永遠不會遺失任何東西。
