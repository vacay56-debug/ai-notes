Anthropic 官方案例庫多以金融、教育、非營利領域為例，但其作業模式與本科業務高度同構。本手冊將官方案例逐一改寫為到院前緊急救護（Emergency Medical Services, EMS）政策業務情境，每一情境均附可直接複製的提示語，並標明應觸發的 Skill 與連接器。

官方提示語三原則｜官方案例頁內建提示語共同採用三個設計：①請 Claude 先問 1–2 個關鍵問題再動工；②主動告知可上傳哪些文件提升品質；③以 Artifact 形式交付成品。以下範例均已內建此三原則。
貳 訓練教材：一份原文，三級產出 Tiered Materials

TECC 原文教材改編為分級講義

改寫自官方案例：Adapt a standard textbook page to every reading level（Cowork ▪ Opus 4.7）

官方示範「單頁教科書 → 三種閱讀程度講義＋一份簡報」。對應本科情境：戰術緊急傷患救護（Tactical Emergency Casualty Care, TECC）章節需同時供 EMT-1、EMT-2、EMT-P 三級使用，且師資班另需授課版。

上傳原文 PDF → Claude 產出分級草稿 → NotebookLM 核對 NAEMT 原典術語 → 回 Claude 定稿
Prompt 貼上即用
我上傳的是 TECC 教材其中一章的原文 PDF。請先讀完整章，然後問我 1–2 個關鍵問題確認改編方向（例如授課時數、是否含技能操作）。

確認後請產出四份成品，均以繁體中文撰寫、英文專業術語首次出現採「中文（英文全稱，縮寫）」格式：

1. EMT-1 版講義：聚焦現場辨識與基本處置，避開進階給藥內容
2. EMT-2 版講義：加入輔助給藥與進階技術範圍內的處置流程
3. EMT-P 版講義：完整涵蓋進階處置、決策節點與例外情況
4. 師資授課大綱：含教學目標、時間分配、常見學員迷思與提問設計

各版本請明確標註「本級可執行／不可執行」的處置界線，依《救護技術員管理辦法》分級架構撰寫。成品以獨立檔案交付。

韌性國家醫療整備計畫：三情境經費配置比較

改寫自官方案例：See budget futures side by side＋See why donor retention beats acquisition（Custom visuals ▪ Sonnet 4.6）

官方示範「輸入預算配置與變數 → 三情境並列圖＋壓力落點解讀」與「附滑桿的五年推估模型」。對應本科情境：年度預算編列前，先以互動圖表向長官說明不同配置的排擠效應，再以 nfa-budget-doc 產出正式預算說明書。

互動圖表定案配置 → 觸發 nfa-budget-doc 產出預算說明書 → nfa-policy-slides 產出報告簡報
Prompt A｜互動情境模擬
請建立一個互動式預算情境比較圖（Artifact），主題為「韌性國家醫療整備計畫」年度經費配置。

四大支用項目：訓練辦理費、教材與器材購置費、國際交流費、委辦研究費。
總額與各項目基準金額我稍後提供，請先問我。

需求：
1. 並列三種情境：基準案、國際交流費刪減 20% 案、訓練量能擴充 15% 案
2. 每項目可拖曳滑桿調整，總額固定、即時顯示排擠效應
3. 金額／百分比一鍵切換
4. 點擊任一情境，以一句話解讀「實際壓力落在哪個業務」
5. 全繁體中文介面，配色採深藍底＋琥珀強調
Prompt B｜接續產出正式文件
依上述定案的基準案配置，撰寫本計畫的預算說明書：含計畫緣起、目標、經費需求說明（分項列明單價與數量依據）、預期效益及績效指標。績效指標請採可量化寫法（訓練人次、合格率、課程開辦數）。

肆 國際比較研究：文獻論證結構圖 Literature Mapping

美日澳 EMS 制度文獻之爭點地圖

改寫自官方案例：Map your lit review mid-conversation（Custom visuals ▪ Sonnet 4.6）

官方示範「整批論文 → 依主張分群、標示學派張力線與各群盲點」。對應本科情境：撰寫國際比較報告前，先把手上的美、日、澳文獻整理成論證地圖，看清各國制度設計的根本歧異，再決定我方政策建議的立足點。

上傳文獻 PDF 批次 → Claude 繪爭點地圖 → 疑義段落交 NotebookLM 溯源 → 回 Claude 寫比較報告
Prompt 貼上即用
我正在進行國際 EMS 制度比較研究，主題是「延長傷患照護（Prolonged Casualty Care, PCC）納入民間救護訓練體系的可行性」。我會上傳美國、日本、澳洲的文獻與官方文件。

請讀完全部文獻後，在對話中繪製一張互動論證結構圖：
1. 依核心主張分群（如：主張軍民課程直接轉譯 vs. 主張民用化改寫）
2. 於立場衝突處標示張力線，註明爭點（法規授權、給藥範圍、訓練時數）
3. 標示各群文獻的共同盲點或未處理的問題
4. 每個節點可點擊展開該文獻的關鍵論據與出處頁碼

圖表完成後，另以文字總結：若以臺灣《緊急醫療救護法》現行架構為前提，哪一條路徑的修法成本最低。

訓練課程先修關係圖：課綱調整前的依賴檢查

改寫自官方案例：Plan your syllabus（Custom visuals ▪ Sonnet 4.6）

官方示範「附課綱 → 標示哪些週次被先修條件鎖定、哪些可調動」。對應本科情境：檢討 EMT-P 訓練課程表時，先確認哪些課目有硬性先修依賴（如給藥須先修藥理），避免調動後產生教學斷層。

Prompt 貼上即用
我上傳的是現行 EMT-P 訓練課程表。請分析各課目間的知識依賴關係，在對話中繪製互動課程結構圖：

1. 以顏色區分「受先修條件鎖定」與「可自由調動」的課目
2. 點擊任一課目，顯示其先修依賴鏈與依據理由
3. 若我拖動課目順序，即時標示會被打斷的依賴關係

分析時請以救護技能養成邏輯為準（解剖生理 → 評估 → 處置 → 整合演練），有疑義的依賴關係先列出來問我，不要自行假設。

伍 連接器工作流：Drive／Gmail 串接公文產製 Connector Workflows

從往來郵件與雲端檔案直接起草函稿

改寫自官方案例：Draft a credit memo from spreads and statements（Connectors ▪ Sonnet 4.6）

官方示範「連接器調資料 → Excel 算數字 → Word 寫備忘錄」的跨工具鏈。對應本科情境：跨機關協調案（如與衛生福利部函復）常散落在多封郵件與雲端會議紀錄中，可讓 Claude 先彙整脈絡，再直接起草三段式函稿。

Gmail 檢索往來郵件 → Drive 調會議紀錄 → 觸發 nfa-gongwen 產出函稿
Prompt 貼上即用
請協助我起草一份函，受文者為衛生福利部，主題是【填入案由，例：PCC 訓練課程給藥項目之權責釐清】。

步驟：
1. 先用 Gmail 搜尋近三個月與本案相關的往來郵件，摘要雙方目前立場
2. 再到 Google Drive 找出本案的會議紀錄檔案，整理已達成共識與待決事項
3. 彙整後先向我確認：本函的核心訴求與期望對方採取的行動
4. 確認後以三段式公文格式（主旨、說明、辦法）起草函稿，說明段落逐項援引前述郵件與會議紀錄的具體日期與結論

引用來源請逐一列出讓我核對，不確定的事實不要寫入函稿。

教材資料夾一致性稽核

改寫自官方案例：Audit a folder of visual assets against your guidelines（Cowork ▪ Opus 4.7）

官方示範「指定素材資料夾＋規範文件 → 回傳附信心評等的違規清單」。對應本科情境：歷年 TECC／PCC 簡報與講義由不同講師產製，術語譯名、分級標示、版面規範不一，可批次檢核。

Prompt 貼上即用
請到 Google Drive 讀取【填入資料夾名稱】內全部教材檔案，依下列規範逐檔稽核：

1. 術語一致性：英文縮寫首次出現須採「中文（英文全稱，縮寫）」格式；TECC、PCC、TCCC、PHTLS 譯名須與我方標準對照表一致（對照表我另外上傳）
2. 分級標示：涉及處置項目處，須標明適用級別（EMT-1／EMT-2／EMT-P）
3. 版本資訊：封面或頁尾須有修訂日期（民國紀年）

產出稽核清單：檔名、問題類型、所在頁次、建議修正文字、信心評等（高／中／低）。信心「低」者僅列出待人工確認，不要直接下結論。

陸 簡報與報告：Gamma 串接產出 Slides & Reports

國際考察成果：出國報告＋長官簡報一次到位

套用官方「跨產品工作流」模式（Cowork → Excel → PowerPoint 之公部門對應）

官方金融案例的精髓是「一份資料，沿工作鏈流轉為多種成品」。對應本科情境：出國考察返國後，同一批考察筆記須同時產出正式出國報告與向長官簡報兩種成品。

上傳考察筆記 → nfa-overseas-report 產出報告 → nfa-policy-slides 定架構 → Gamma 產製視覺簡報
Prompt 貼上即用
我剛結束赴【國家】的 EMS 制度考察，上傳的是每日考察筆記與蒐集的資料。請依序完成兩件事：

第一步：撰寫出國考察報告，含目的、行程、考察發現（依機構分節）、與我國制度之比較分析、具體建議（區分短期可行／須修法／須跨部會協調三類）。動工前先問我報告的核心政策問題是什麼。

第二步：報告定稿後，萃取為 10 頁以內的簡報大綱（對象：署長層級，每頁一個重點訊息），並直接以 Gamma 產製簡報，風格採政府正式簡報、深藍主色調。
