以美國聯邦緊急事務管理署（Federal Emergency Management Agency, FEMA）2020 年 1 月版《國土安全演習與評估計畫》（Homeland Security Exercise and Evaluation Program, HSEEP）doctrine 原文為唯一基準，逐項核對附件圖卡之敘述，標示相符、應補充與應修正之處。本報告不新增任何未見於來源文件之內容。

01查證結論

整體結論：圖卡主體正確，但有二處架構性用語需修正、一處英文誤植需更正。

  • 相符　七種演習類型的分類與定義完全對應 doctrine 第 2 章：討論型 4 類（研討會、工作坊、桌上型演習、遊戲）、操作型 3 類（戰技操演、功能演習、全尺度演習）。
  • 相符　「無責備環境（no-fault environment）」確為 doctrine 原文用語，載於桌上型演習之執行特性欄位。
  • 相符　「不必然逐一闖關」之敘述正確；doctrine 明載漸進式演習規劃不必然是演習類型的線性推進。
  • 應補充　「三大核心原則」非 doctrine 用語。2020 年版明列六項基本原則（Fundamental Principles），圖卡三項屬教學濃縮，且遺漏「高階領導指導」「以風險為依據」「全社會整合」「共同方法論」四項。
  • 應修正　「六步驟循環」與 doctrine 不符。HSEEP Cycle 為五階段（專案管理、設計與開發、執行、評核、精進規劃）；圖卡之六步驟較接近我國基礎課程「設計—執行—評核—精進」的教學轉譯，不宜標示為 HSEEP 原架構。
  • 應修正　圖卡英文誤植「Improvement Planing」，正確為 Improvement Planning；且 doctrine 之標準用語為事後檢討報告／精進計畫（After-Action Report / Improvement Plan, AAR/IP）併稱。
相符 圖卡敘述可於 doctrine 原文對應 應補充 敘述無誤但不完整或非原文用語 應修正 與 doctrine 架構或用語不一致

02逐項查證明細

依圖卡版面由上而下編號，逐段核對。

A-01相符

「HSEEP 是美國國土安全體系所發展的演習與評核方法，用來建立、維持與驗證能力。」

doctrine 定義 HSEEP 為一套演習計畫的基本原則與共同方法，涵蓋專案管理、設計與開發、執行、評核及精進規劃。演習被定位為整備的重要環節，讓全社會有機會形塑計畫、評估與驗證能力並找出待改善事項。

其適用性具彈性、可調整規模、可調適，適用於預防、保護、減災、應變、復原五大任務領域。

來源：HSEEP 2020, Introduction／Applicability and Scope

A-02相符

「七種演習類型：討論型四類、操作型三類。」

doctrine 第 2 章明列討論型演習包含研討會、工作坊、桌上型演習與遊戲，用於熟悉或發展新的計畫、政策、程序與協定，聚焦策略與政策層次議題，由引導者或簡報者主持。操作型演習包含戰技操演、功能演習與全尺度演習，用於驗證計畫、政策、程序與協定，釐清角色職責並找出資源缺口，且涉及即時反應行動（如啟動通信、動員人力與資源）。

來源：HSEEP 2020, §2 Discussion-Based / Operations-Based Exercises

A-03應補充

「掌握 HSEEP 的三大核心原則。」

doctrine 第 1 章列出的是六項基本原則，缺一不可（完整內容見第 4 節）。圖卡三項可對應其中：第 1 項「演習、計畫與政策必須連結」對應「以能力為基礎、以目標為導向」及整合整備計畫（IPP）的串接邏輯；第 2 項「循序漸進」對應「漸進式演習規劃取向」；第 3 項「找問題、改問題」對應評核與精進規劃的目的。

圖卡未呈現之四項為：高階領導指導、以風險為依據、全社會整合、共同方法論。其中「高階領導指導」在 doctrine 中被列為演習計畫成功的關鍵，於機關導入時不宜省略。

來源：HSEEP 2020, §1 Fundamental Principles

A-04相符

「桌上型演習應鼓勵參與者在無責備環境（no-fault environment）中自由探索問題。」

doctrine 桌上型演習的「執行特性」欄位明載：應鼓勵所有參與者投入討論，並提醒其係在無責備環境下作成決策。同欄位另載明桌上型演習需要具經驗的引導者、深度討論與解決問題的環境。

來源：HSEEP 2020, Table 2.5 Tabletop Exercise

A-05相符

「這並不代表一定要按照七種演習一個一個『闖關』。」

doctrine 於基本原則中明確載明：漸進式演習規劃取向係指運用多種演習、錨定同一組計畫優先事項與目標，並隨時間提高複雜度；此一取向不必然意味演習類型的線性推進。圖卡此段敘述與原文一致。

來源：HSEEP 2020, §1 Progressive Exercise Planning Approach

A-06應補充

階梯圖示「戰技操演 → 功能演習 → 全尺度演習」。

此圖示僅呈現操作型三類，易被解讀為「唯有操作型演習才算能力進階」。doctrine 的漸進性描述為：多年期演習計畫使機關參與一系列複雜度漸增的演習，每場演習均建立在前一場之上；而全尺度演習的設計目的之一，正是實作與分析在討論型演習中發展、並於先前較小型演習中打磨過的計畫、政策與程序。

建議於階梯前端補入討論型演習，以完整呈現「先討論建立、再操作驗證」的路徑。

來源：HSEEP 2020, §2 Progressive Approach；Table 2.9 Full-Scale Exercise

A-07應修正

「HSEEP 的循環：討論 → 規劃 → 執行 → 評核 → 精進 → 再規劃（六步驟）。」

doctrine 定義之 HSEEP Cycle 為五階段：專案管理、演習設計與開發、演習執行、演習評核、精進規劃。另有一個層級更高的整合整備循環（Integrated Preparedness Cycle）：規劃、組織／裝備、訓練、演習、評核／精進，演習階段即由此銜接進入 HSEEP Cycle。

圖卡六步驟並非上述任一架構之原文，且將「討論」列為循環起點易與「討論型演習」混淆。建議改採五階段原架構，或明確註記為教學轉譯版本。

來源：HSEEP 2020, §1 The HSEEP Cycle；§2 Integrated Preparedness Cycle

A-08應修正

「事件後報告（AAR）與精進規劃（Improvement Planing）」。

英文誤植，正確拼寫為 Improvement Planning。另 doctrine 之標準用語為事後檢討報告／精進計畫（After-Action Report / Improvement Plan, AAR/IP）併稱：演習評核透過記錄優勢、待改善事項、能力表現與矯正措施於 AAR/IP 中，評估目標與能力之達成程度；再透過精進規劃落實矯正措施。矯正措施本身亦須符合 SMART 原則並追蹤至結案。

來源：HSEEP 2020, Introduction；§5 AAR/IP；§6 SMART Corrective Actions

A-09相符

「用了 HSEEP 的名詞，不代表就用了 HSEEP 的精神。」

此為觀點性表述，doctrine 無對應原句，但方向與 FEMA 官方立場一致：FEMA 已不使用「HSEEP compliant（符合 HSEEP）」「HSEEP certified（HSEEP 認證）」等說法，正式用語為「與 HSEEP 一致（HSEEP consistent）」；HSEEP 提供的是指導與工具，並不強制對齊特定格式或產出物。

來源：HSEEP Frequently Asked Questions（2020）

討論型演習（Discussion-Based Exercises）

類型目的執行特性主要產出
研討會Seminar 建立共同理解框架；作為新訂或大幅修訂計畫、政策、程序的起點。 授課式，多為簡報、專家小組或個案討論；由引導者／簡報者帶領；參與者回饋與互動有限；時間限制少，適用大小規模團體。 紀錄討論內容、所提議題與行動事項之報告；AAR/IP。
工作坊Workshop 發展政策、計畫或程序；聚焦特定議題並產出具體成果。 參與者互動高於授課；目標與產出明確；常運用分組討論探討議題不同面向；相關利害關係人廣泛出席。 緊急應變計畫、相互支援協定、標準作業程序、營運持續計畫、工作坊摘要報告；AAR/IP。
桌上型演習Tabletop Exercise, TTX 就情境引發各項議題討論，促成概念性理解、找出優勢與待改善事項，或改變對計畫、政策、程序的認知。 設定模擬時間點的情境；參與者就引導者提出的問題群運用知識與技能，以團體方式討論並可作成結論供後續分析；需具經驗的引導者；無責備環境。 對現行計畫、政策、程序的修正建議；AAR/IP。
遊戲Game 模擬作業運作以探索參與者決策與行動的後果；辨識關鍵決策點為評估成效的重要因素。 結構化的競賽或非競賽形式，依規則、資料與程序進行，通常兩隊以上；決策節奏可緩慢審慎或快速高壓；可納入「若則（what-if）」提問；不動用實際資源。 驗證計畫、政策、程序或評估資源需求；AAR/IP。

操作型演習（Operations-Based Exercises）

類型目的執行特性主要產出
戰技操演Drill 驗證單一機關內的特定功能或能力；提供新裝備訓練、驗證程序或維持既有技能。 可獨立辦理或成系列辦理；須先具備明確的計畫、程序與協定；即時回饋、擬真環境、焦點狹窄、單項表現，並依既定標準衡量結果。 判斷計畫是否可依設計執行、是否需追加訓練、強化最佳實務；AAR/IP。
功能演習Functional Exercise, FE 在擬真、即時的環境中驗證多項功能、次功能或相互依存的活動群；檢驗管理、指揮與管制層級的計畫、政策、程序與人員。 以情境事件推進，驅動管理層級活動；管制人員運用主要情境事件清單（Master Scenario Events List, MSEL）確保演習在預定範圍內；資源與人力調度通常為模擬；設模擬小組（SimCell）與管制、評核人員。 對災害應變中心（EOC）、指揮所、幕僚之管理評估；表現分析；強化協力關係；AAR/IP。
全尺度演習Full-Scale Exercise, FSE 通常為最複雜、資源最密集的類型；聚焦實作與分析先前於討論型演習中發展、於較小型演習中打磨過的計畫、政策與程序。 涉及多機關、多組織、多轄區，並有資源之即時實際調度；常於事故指揮體系（ICS）統一指揮下運作；以 MSEL 驅動、模擬小組投入事件；場地大、活動同時進行，後勤與安全（含道具與特效使用）須嚴密監控。 驗證計畫、政策、程序；評估資源需求；AAR/IP。

05循環架構對照

HSEEP Cycle（doctrine 原架構）

FIVE PHASES
  1. 專案管理　整合資源與各方，確認並達成計畫優先事項，由高階領導提供長期監督。
  2. 演習設計與開發　依領導意圖與優先事項形塑單場或系列演習，納入風險評估、計畫政策程序、補助要求及既往 AAR/IP。
  3. 演習執行　含演習前準備、演習進行管理與立即性收尾；操作型演習涵蓋自演習開始（StartEx）至演習結束（EndEx）之全部作業。
  4. 演習評核　依演習目標評估表現，記錄優勢與待改善事項；自訂定目標階段即應納入考量。
  5. 精進規劃　落實矯正措施，強化機關在規劃、組織／裝備、訓練、演習各面向的能力。

整合整備循環（Integrated Preparedness Cycle）

HIGHER-LEVEL CYCLE
  1. 規劃　Planning
  2. 組織／裝備　Organizing / Equipping
  3. 訓練　Training
  4. 演習　Exercising　← 由此銜接進入 HSEEP Cycle
  5. 評核／精進　Evaluating / Improving

此循環持續檢視變動中的威脅、危害與風險，透過多年期整合整備計畫（Integrated Preparedness Plan, IPP）與整合整備規劃工作坊（Integrated Preparedness Planning Workshop, IPPW）產生演習計畫優先事項。

與圖卡差異：圖卡的六步驟（討論→規劃→執行→評核→精進→再規劃）在 doctrine 中並無對應條文，較接近我國基礎課程「演習設計、執行、評核及精進」的教學表述。建議標示為「教學轉譯版」，避免與 doctrine 原架構混用。

安全與保安涉及具危險性之實地演練或機敏資料時，管制團隊應指定安全與／或保安管制官，並安排不參演的實地醫療與緊急救護支援。

07我國導入現況（公開資料查證）

08圖卡建議修正清單

序現行圖卡文字建議修正
1掌握 HSEEP 的三大核心原則改為「HSEEP 六項基本原則（本圖擇要說明其中三項）」，或於標題加註「教學摘要」。
2HSEEP 的循環：討論→規劃→執行→評核→精進→再規劃改為 doctrine 五階段：專案管理→設計與開發→執行→評核→精進規劃；如保留六步驟，須加註「我國基礎課程教學版」。
3Improvement Planing更正為 Improvement Planning；並將「事件後報告（AAR）」調整為「事後檢討報告／精進計畫（AAR/IP）」。
4階梯圖僅列 Drill → FE → FSE於階梯前端補入討論型演習，或加註「複雜度示意，非必經順序」。
5（未標示版本）頁尾加註來源版本：FEMA, HSEEP Doctrine, January 2020（取代 2013 年版）。
6戰技操演（Drill）我國各文件譯名不一（另有「操作演練」等）；建議於同一系列教材中統一譯名，並保留英文原文以利對照。
