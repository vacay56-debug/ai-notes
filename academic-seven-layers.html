Structure of Academic Argument　/　剖面圖

學術表達的
七層結構

一篇有力的學術論述不是段落的排列，而是承重結構。從真實世界的現象出發，每一層都由下一層支撐；任何一層失去承載力，上方的結論都會失去依據。

七個層級 由下而上承載 每層回答一個核心問題

真實世界　／　現象發生之處

LEVEL 01基礎層

觀察與現象描述

我們觀察到什麼？有什麼值得探究的現象？

全篇的起點。研究從真實世界的異常、落差或變化出發，先把「發生了什麼」講清楚，再談為什麼要研究它。此層不做任何因果宣稱，只負責兩件事：證明現象確實存在，並讓讀者相信它值得被理解。基礎不實，上方所有層級都是懸空的。

ELEMENT 1.1現象觀察

指出可被辨識、可被量測的具體現象，而非以抽象概念代替事實。描述對象、範圍與時間，讓現象具有邊界。

ELEMENT 1.2初步證據

以描述性統計、趨勢圖、實地觀察或代表性個案，說明現象確實存在且非偶發雜訊。此處只求「看得見」，不求解釋。

ELEMENT 1.3研究背景

交代制度、政策、時空與產業脈絡，使讀者理解現象發生的條件，也界定後續結論可適用的範圍。

常見缺陷

  • 現象描述過於籠統，讀完仍不知道「什麼變了」。
  • 以文獻回顧代替現象觀察，研究失去現實錨點。
  • 一開場即提出因果結論，越過後續所有論證。

檢核點

  • 能否用一句話說明「什麼變了、對誰有影響」？
  • 初步證據是否足以排除偶然波動與資料誤差？

示例近五年某轄區到院前心臟停止（Out-of-Hospital Cardiac Arrest, OHCA）通報案件數持續上升，但恢復自主循環（Return of Spontaneous Circulation, ROSC）比率停滯不前。

LEVEL 02定位層

研究動機與文獻脈絡

為何這個問題重要？現有研究缺少什麼？

把現象轉譯為學術問題。透過既有文獻標定知識的邊界，指出尚未被回答、或被回答得不夠好的部分，並將其收斂為一個可被研究的問題。文獻回顧的功能是論證缺口，不是展示閱讀量。

ELEMENT 2.1問題背景

說明現象為何值得投入——涉及的成本、風險、權益分配或政策決策，讓重要性有具體承載對象。

ELEMENT 2.2文獻缺口

以既有研究的分歧、方法限制或未涵蓋情境界定缺口，而非以「相關研究很少」草率帶過。

ELEMENT 2.3研究問題

以有對象、有範圍、可回答的句式陳述，並與缺口一對一對應。問題的大小決定研究可行性。

常見缺陷

  • 文獻回顧寫成流水帳，只有羅列而無對話。
  • 缺口與研究問題不對應，缺口是 A、卻去研究 B。
  • 研究問題過大，無法以單一研究設計回答。

檢核點

  • 刪掉缺口敘述後，研究問題是否仍站得住？
  • 每一篇被引用的文獻，是否都承擔論證功能？

示例既有文獻多聚焦醫院端處置成效，對到院前救護分級人力配置與存活結果之間的關聯，實證證據仍相當有限。

LEVEL 03推論層

理論基礎與假說發展

為何提出這些假說？理論依據是什麼？

說明「為何預期會出現這樣的關係」。理論負責提供機制，使實證結果不只是一組相關數字，而是可解釋、可遷移、可被後續研究延伸的知識。沒有機制的假說，只是猜測的包裝。

ELEMENT 3.1理論依據

指出所採用的理論或分析觀點，並說明它為何適用於本研究情境，而不是僅作為引用裝飾。

ELEMENT 3.2分析架構

將變數關係、作用路徑與邊界條件具象化，讓讀者一眼看出「誰影響誰、透過什麼機制」。

ELEMENT 3.3研究假說／命題

由機制推導出可被檢驗的方向性陳述；質性研究則以命題或待答問題形式呈現。

常見缺陷

  • 先看到結果、再回頭補寫假說。
  • 理論被引用但未實際承擔推論功能。
  • 分析架構圖與假說內容不一致。

檢核點

  • 每一條假說能否追溯到一段明確的機制敘述？
  • 是否存在同樣合理、但方向相反的競爭解釋？

示例依據處置時效與救護能力層級之作用機制，推論高級救護技術員（EMT-Paramedic, EMT-P）到達時間縮短將提升 ROSC 機率。

LEVEL 04樞紐層

研究方法與識別策略

我們如何得到這些結果？為何方法是合理的？

交代取得結果的完整程序，並論證為何此一設計足以支撐因果或關聯宣稱。這是全篇可信度的樞紐：方法寫得清楚，結果才有重量；識別策略（identification strategy）不明說，再漂亮的係數也只是相關。

ELEMENT 4.1研究設計

說明採取實驗、準實驗、觀察性或質性設計的理由，以及該設計如何對應研究問題的性質。

ELEMENT 4.2資料來源

界定母體、抽樣方式、期間、變數操作型定義與資料品質限制，使研究具備可重現性。

ELEMENT 4.3識別假設

明確寫出因果推論所依賴的前提，並提供支持該前提成立的檢驗或佐證。

常見缺陷

  • 只描述操作步驟，未論證方法的正當性。
  • 識別假設隱而不談，讓讀者自行推測。
  • 樣本範圍與研究問題所指母體不一致。

檢核點

  • 他人能否僅依本節重現整個研究流程？
  • 最可能的內生性來源是什麼？如何被處理？

示例以各縣市分階段導入時點作為差異中之差異（Difference-in-Differences, DID）設計基礎，並檢驗導入前的平行趨勢假設。

LEVEL 05證據層

研究結果

我們發現了什麼？結果是否穩健？

呈現發現本身，並證明它不會因為設定、樣本或衡量方式的合理調整而崩解。此層負責事實，不負責意義；意義留給下一層。報表不會自己說話，必須由文字引導讀者看見重點。

ELEMENT 5.1實證發現

報告主要結果的方向、效果量與精確度，並以實務意義說明其大小，而非僅停留在統計顯著。

ELEMENT 5.2穩健性檢驗

更換設定、樣本、衡量方式或估計方法，檢視結論是否維持一致，主動測試自己的結果。

ELEMENT 5.3附加分析

異質性、次群體與機制檢驗，回答「在誰身上、透過什麼路徑」效果較強或消失。

常見缺陷

  • 表格直接貼上，未指出讀者該看哪一格。
  • 只報告顯著結果，隱去不利發現。
  • 把穩健性檢驗視為附屬，草草交代。

檢核點

  • 主要結果是否以效果量與實務意義陳述？
  • 結論是否僅依賴單一設定才成立？

示例估計結果顯示反應時間每縮短一分鐘，ROSC 機率上升若干百分點；於不同時間窗與縣市子樣本下維持一致。

LEVEL 06詮釋層

討論與詮釋

結果代表什麼？與過去研究有何異同？有何限制與可延伸處？

把數字轉回知識。回答結果的意義、與既有文獻一致或衝突之處、以及在什麼條件下成立。討論不是結果的重述，而是研究者在證據之上所做的判斷，並誠實標示這些判斷的邊界。

ELEMENT 6.1結果詮釋

將發現扣回第三層的機制，說明證據支持了哪一條推論路徑、又推翻了哪一條。

ELEMENT 6.2與文獻對話

指出與既有研究一致與不一致之處，並解釋差異來源：情境、樣本、期間或方法。

ELEMENT 6.3限制與延伸

說明結論的適用邊界，並將限制轉化為後續研究可著手的具體設計，而非免責聲明。

常見缺陷

  • 整段重複結果，未提出任何新的判斷。
  • 只挑選對自己有利的文獻進行對照。
  • 限制寫成套語，與研究設計無實質關聯。

檢核點

  • 與預期不符的結果是否被誠實處理？
  • 每一項限制是否連結到可行的後續設計？

示例結果與都會區研究一致，但在偏遠地區效果減弱，顯示運送距離可能構成機制的邊界條件。

LEVEL 07影響層

學術貢獻與影響

為何這項研究重要？對學術或實務有何影響？

說明這項研究改變了什麼。貢獻不等於「填補了文獻缺口」，而是明確指出：因為這篇研究，哪些理解被修正、哪些決策有了新依據、哪些問題現在才問得出來。

ELEMENT 7.1理論貢獻

指出對既有理論的修正、擴充或邊界界定，說明知識版圖具體移動了多少。

ELEMENT 7.2實務影響

將發現轉為可執行的決策建議，並標明適用對象、前提條件與預期效果。

ELEMENT 7.3未來研究

提出由本研究直接衍生、且已具備可行路徑的下一步題目，而非泛泛的期許。

常見缺陷

  • 以「填補研究缺口」代替具體貢獻陳述。
  • 實務建議超出結果所能支持的範圍。
  • 未來研究流於客套，缺乏可執行性。

檢核點

  • 若抽掉這篇研究，哪些判斷會失去依據？
  • 建議是否明確標示適用條件與限制？

示例研究結果可作為救護人力配置與分級派遣政策調整之實證依據，並界定其適用之地理與時間條件。

承重原則

  • 層層相扣：前一層是後一層的基礎，順序即是論證。
  • 單一焦點：每一層只回答一個核心問題，不代管其他層的工作。
  • 避免跳層：夯實基礎才能支撐結論；跳過的層級最終都會回頭追討。
  • 清楚表達：研究先被理解，才可能被信任、被引用、被採用。

整體目標

從真實世界的現象出發，透過系統性的研究與嚴謹的論述，提出有價值、可驗證、能推廣的知識，進而推動學術與實務的進步。
