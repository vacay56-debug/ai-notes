先掌握核心：4D 應用力框架

第 2、8、9、10、11 門課程共用之核心框架。理解此框架，後續各門「AI 應用力」系列課程即可快速吸收。

委派Delegation

判斷哪些工作交給 AI、哪些由人主導，以及人機如何分工。

描述Description

清楚說明目標、脈絡、格式與限制，讓 AI 產出符合需求。

辨識Discernment

評估 AI 產出之正確性、完整性與偏誤，不盲目採信。

盡責Diligence

對 AI 協作成果負最終責任，兼顧資安、倫理與透明揭露。

1Claude 101Claude 1011 小時 00 分
基礎

課程定位

給所有日常使用者的第一門課。學習如何將 Claude 用於一般工作任務，熟悉核心功能，並了解後續進階學習資源。

學習重點

  • Claude 介面操作：對話、上傳檔案、專案（Projects）與知識庫。
  • 撰寫有效提示詞：明確目標、提供背景、指定輸出格式。
  • 常見工作情境：摘要、改寫、資料整理、草擬文件。
  • 產出物（Artifacts）、網頁搜尋等功能運用。
  • 認識 Claude 的限制與查證習慣。

學完產出

能以 Claude 穩定完成日常文書與資訊整理工作。

救護業務應用

建立「公文草擬」「會議紀錄摘要」專案，上傳《緊急醫療救護法》及相關辦法作為知識庫，快速檢索條文並草擬簽稿。

前往課程
2AI 應用力：框架與基礎AI Fluency: Framework & Foundations1 小時 10 分
基礎

課程定位

不限特定工具，建立與 AI 有效、有效率、合乎倫理且安全協作的思維模式。整個 AI 應用力系列之核心課程。

學習重點

  • 4D 框架：委派、描述、辨識、盡責。
  • 生成式 AI 運作原理、能力邊界與常見錯誤（如幻覺）。
  • 三種人機協作模式：自動化、增強、代理。
  • 課程含多段影音與測驗，完成後取得證書。

學完產出

具備判斷「何時用 AI、如何用、如何驗證」之系統性框架。

救護業務應用

作為機關內部 AI 使用規範之理論基礎；「辨識」與「盡責」可直接轉化為政策文件、統計數據引用前之查核流程。

前往課程
3Agent 技能入門Introduction to Agent Skills1 小時 30 分
開發者

課程定位

理解 AI 代理（Agent）如何思考、規劃與行動，並學習以技能（Skills）封裝可重複使用之工作方法。

學習重點

  • 技能的結構：SKILL.md 說明檔、參考資料、腳本。
  • 技能的觸發機制與描述撰寫。
  • 將團隊慣例、格式規範、作業流程轉為技能。
  • 技能於 Claude、Claude Code 及 API 之共用方式。

學完產出

能自行撰寫技能，使 Claude 每次都依相同標準執行特定任務。

救護業務應用

將公文三段式格式、預算說明書架構、採購規格書範本封裝為技能，確保產出一致符合機關體例。

前往課程
4使用 Claude API 建構應用Building with the Claude API8 小時 10 分
開發者

課程定位

系列中最完整、時數最長之課程。全面涵蓋透過應用程式介面（Application Programming Interface, API）使用 Anthropic 模型之各面向。

學習重點

  • API 基礎：訊息格式、多輪對話、系統提示詞、參數控制。
  • 提示詞工程與評估（Evaluation）：如何量化測試輸出品質。
  • 工具使用（Tool Use）：讓 Claude 呼叫外部函式。
  • 檢索增強生成（Retrieval-Augmented Generation, RAG）：以自有文件回答問題。
  • 進階功能：延伸思考、圖片與 PDF 輸入、引用、提示快取。
  • MCP 與代理工作流程概論。

先備條件

建議具備 Python 基礎。

學完產出

能開發整合 Claude 之應用程式或內部工具。

救護業務應用

建置救護法規問答系統（RAG）、救護紀錄表文字自動分類、教材題庫自動生成等內部工具之技術基礎。

前往課程
5Claude Code 實戰Claude Code in Action1 小時 50 分
開發者

課程定位

將 Claude Code 整合進開發工作流程，學習操控、設定、自動化與驗證長時間的代理式開發作業。

學習重點

  • Claude Code 運作方式：讀取專案、規劃、修改檔案、執行指令。
  • 專案記憶檔（CLAUDE.md）與脈絡管理。
  • 自訂指令、掛鉤（Hooks）與 MCP 伺服器擴充。
  • 與 GitHub 整合、程式碼審查與自動化。

學完產出

能以 Claude Code 從零建立或維護小型軟體專案。

救護業務應用

開發 HTML 訓練模擬器、檢傷分類練習工具、採購執行進度儀表板等單機網頁工具，並以 GitHub 版本控管。

前往課程
6模型上下文協定入門Introduction to Model Context Protocol (MCP)2 小時 10 分
開發者

課程定位

模型上下文協定（Model Context Protocol, MCP）是連接 AI 與外部工具、資料、系統之開放標準。本課程以 Python 從零實作 MCP 伺服器與用戶端。

學習重點

  • MCP 架構：主機、用戶端、伺服器之角色分工。
  • 三大核心元件：工具（Tools）、資源（Resources）、提示（Prompts）。
  • 以 Python SDK 建立 MCP 伺服器並測試。
  • 將 MCP 伺服器接入 Claude。

學完產出

能讓 Claude 直接存取指定資料庫、檔案系統或內部服務。

救護業務應用

將救護統計資料、EMT 證照名冊、訓練開班紀錄等以 MCP 接入，使 Claude 可直接查詢並產製分析報告（須先評估資安與個資規範）。

前往課程
7MCP：進階主題Model Context Protocol: Advanced Topics2 小時 00 分
開發者

課程定位

接續第 6 門，聚焦正式環境（Production）之 MCP 伺服器開發模式。

學習重點

  • 取樣（Sampling）：伺服器反向請求模型生成內容。
  • 通知（Notifications）與進度回報。
  • 根目錄（Roots）與檔案系統存取控管。
  • 傳輸機制：標準輸入輸出（stdio）與可串流 HTTP。

先備條件

須先完成第 6 門。

救護業務應用

跨單位資料整合之架構規劃參考，例如消防局與衛生局系統間之安全資料介接。

報名與取得證書

  1. 前往 Anthropic 學院課程目錄：anthropic.skilljar.com。
  2. 以電子郵件註冊帳號（免費）。
  3. 選擇課程並點選報名，依章節觀看影音、閱讀教材、完成練習。
  4. 通過課程測驗後，系統核發結業證書，可下載或新增至 LinkedIn 個人檔案。
  5. 平台自動記錄學習進度，可隨時中斷續讀。

學習建議

  • 邊看邊做：每學一個概念，即以實際業務（公文、簡報、教材）測試。
  • 開發者課程程式範例以 Python 為主，零基礎者建議先完成第 5 門，由 Claude Code 協助理解程式。
  • 課程語言為英文，可開啟瀏覽器翻譯或將講義貼入 Claude 翻譯摘要。
  • 涉及機關資料時，應遵循機關資通安全與個人資料保護規範，不上傳機敏資料。
