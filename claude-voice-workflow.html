三層後送。
打造 Claude 專屬語氣

借鏡到院前救護「分級後送」的概念——依嚴重度與情境層層轉介、逐級補強——將 Claude 的語氣建置拆為基礎層、專案層、技能層三級架構。三層依序疊加於每一次對話，任何一層缺席，Claude 便會以通用 AI 語氣填補空缺。

三層各司其職，缺一層即失真

基礎層（Profile）決定 Claude 知道「你是誰」；專案層（Project）補足「這件業務的情境與知識」；技能層（Skills）決定「最終輸出的語氣與格式」。三層須分工明確，規則不可重複——重複規則反而會稀釋各層效果。

三層建置 SOP

基礎層・個人化設定

PROFILE SETUP
LAYER 1 · 全帳號通用
建置步驟
  • 1路徑：設定 ＞ 一般 ＞ 個人資料 ＞「給 Claude 的指示」。
  • 2寫出身分＋不變原則：職稱、業務範圍，加上 5–8 條永遠不變的規則（例：一律使用繁體中文、公文採三段式）。
  • 3全帳號生效：每次新對話最先載入，優先於「專案」與「風格」設定。
容量
1.5K
字元上限，空間最緊。只收「不隨案件變動」的規則，每個字都要有存在價值。
實務要訣

各層規則不可重複。身分寫在這層，業務規則放進「專案」，語氣規則放進「技能」，重複只會稀釋三層效果。

專案層・知識庫建置

CLAUDE PROJECT
LAYER 2 · 業務大腦
建置步驟
  • 1依業務別建立專案：如「緊急救護科政策研究」「CIT 國際研討會」「解毒劑採購案」，規則寫入「自訂指示」。
  • 2上傳專案知識庫：法規條文、歷年公文、會議紀錄，Claude 會引用真實文件內容作答，而非憑空生成。
  • 3加入「不可做」清單：負面表列規則優先於正面表列，更能約束輸出。
容量
8K
字元指示，另有 20 萬 tokens 上傳知識庫額度。需付費方案，該專案內每次對話自動套用。
實務要訣

省略確認式提問：在指示中加入「略過確認、直接產出草稿並註明假設」，每次都能省下一輪來回。

範例：「若使用者未指定文號或日期，逕以合理假設產出，並於文末註明待確認事項。」

技能層・語氣與格式

CLAUDE SKILLS
LAYER 3 · 語氣呈現
建置步驟
  • 1建立技能資料夾：內含 SKILL.md（語氣規則）＋ 3–5 份範例文件。
  • 2上傳或請 Claude 協助建置：於「風格與偏好」上傳 ZIP，或直接與 Claude 對話共同建置。
  • 3寫好 description：這段文字決定 Claude 何時自動判斷啟用此技能，寫得越精準，誤判率越低。
容量
3–5
份範例文件即可，挑「最像自己語氣」的文件，而非最新的——範例決定語氣天花板。
實務要訣

一技能對應一任務：公文、預算書、簡報、採購各自獨立成技能，Claude 會依需要自動疊加組合使用。

例：nfa-gongwen ＋ nfa-budget-doc 可同時處理一份「預算追加簽案」。
執行流程 · 四步驟訓練循環

建置滾動流程

01 · COLLECT

收集

找出近期最常被原文核定、退回修改次數最少的 5 份文件（公文、簡報、報告皆可），作為三層共用的訓練基礎。

›
02 · FEED

餵入

範例文件放進技能資料夾；法規與歷年檔案放進專案知識庫；身分與不變規則寫進個人資料。

›
03 · RULE

訂規則

指示至少 200 字起跳，太短效果有限。先列「不可做」清單，再列「必須做」清單。

›
04 · REFINE

精煉

每使用 3–5 次後，找出Claude 重複出現的錯誤，回頭修正對應那一層的規則，效果會隨時間快速疊加。
